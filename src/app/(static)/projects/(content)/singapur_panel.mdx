## Acerca del Proyecto

Este panel administrativo fue desarrollado para **Singapur Ingeniería**, una empresa especializada en consultoría ambiental y técnica. El sistema permite registrar cotizaciones de servicios, gestionar datos de clientes y centralizar la información operativa de manera eficiente y segura.

## Funcionalidades Clave

- Creación de cotizaciones con múltiples servicios y parámetros.
- Gestión de clientes con historial vinculado a cada cotización.
- Configuración de servicios, precios y equipos técnicos.
- Panel limpio y navegable con enfoque en la productividad interna.

## Estilo Visual

- **Diseño Minimalista**: Interfaz clara, con navegación lateral y estructura modular.
- **Tipografía Profesional**: Facilita la lectura y la generación de documentos.
- **Optimizado para uso interno**: Pensado para rendimiento y organización.
