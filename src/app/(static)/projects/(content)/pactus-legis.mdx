Este proyecto consiste en el desarrollo de una página web tipo landing page profesional para un centro de conciliación extrajudicial llamado Pactus Legis. La web será desarrollada utilizando Astro como framework principal y TailwindCSS para el diseño y la estilización.

El objetivo principal es ofrecer una experiencia elegante, profesional y accesible para los usuarios interesados en los servicios de conciliación de la empresa.


<img src="/projects/pactus-legis/screenshot_landing.png" className="w-full object-contain rounded-lg mt-8" alt="Contain" />

## Objetivos del Proyecto

- Crear una landing page profesional, moderna y minimalista que refleje la seriedad y profesionalismo de Pactus Legis.
- Implementar un diseño responsive que se adapte a todos los dispositivos.
- Optimizar la web para SEO y rendimiento mediante buenas prácticas en Astro.
- Incluir secciones relevantes como servicios, contacto, información sobre la empresa y testimonios.

## Estilo Visual

- Paleta de colores: Azul oscuro, blanco y dorado para transmitir elegancia, profesionalismo y confianza.
- Tipografía: Fuentes serif para títulos y sans-serif para contenido principal, creando un balance entre formalidad y accesibilidad.
- Uso de espacios en blanco para mejorar la legibilidad y elegancia.
- Animaciones suaves al desplazarse entre secciones.
- Compatibilidad con todos los navegadores modernos.
