## Acerca del Proyecto

Este diseño forma parte de una colaboración visual realizada para **CodeIQ**, una empresa destacada en el desarrollo de scripts para servidores de **FiveM**. El enfoque fue rediseñar por completo la interfaz del **Pause Menu de FiveM**, un sistema altamente personalizable compatible con **QBCore** y **ESX** que mejora la organización y la inmersión de los jugadores dentro de servidores de rol.

¿Buscas un rediseño similar para tu servidor FiveM? En [Neenbyss](/services/fivem) diseñamos y desarrollamos interfaces NUI personalizadas (pause menu, HUD, phone, inventarios) y scripts a medida. Revisa nuestros [servicios FiveM](/services/fivem) para ver planes y precios.

## Importante

> 🧠 Nosotros participamos exclusivamente en la fase de diseño de interfaz (UI), no en el desarrollo del sistema o sus funcionalidades técnicas. Todo el crédito por el desarrollo del script pertenece a [CodeIQ](https://store.codeiq.xyz/).

- Personalización completa de branding (logo, colores, fondos).
- Integración de audio para interacciones.
