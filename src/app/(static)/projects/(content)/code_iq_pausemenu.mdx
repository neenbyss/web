## Acerca del Proyecto

Este diseño forma parte de una colaboración visual realizada para **CodeIQ**, una empresa destacada en el desarrollo de scripts para servidores de FiveM. El enfoque fue rediseñar por completo la interfaz del **Pause Menu**, un sistema altamente personalizable que mejora la organización y la inmersión de los jugadores.

## Importante

> 🧠 Nosotros participamos exclusivamente en la fase de diseño de interfaz (UI), no en el desarrollo del sistema o sus funcionalidades técnicas. Todo el crédito por el desarrollo del script pertenece a [CodeIQ](https://store.codeiq.xyz/).

## Características del Script (desarrolladas por CodeIQ)

- Personalización completa de branding (logo, colores, fondos).
- Integración de audio para interacciones.
- Configuración de accesos directos dinámicos.
- Secciones de facturas, propiedades, servicios, negocios y más.
- Compatibilidad con **QBCore**.

## Estilo Visual Aplicado

- **Estética Neón & Gamer**: Adaptada al estilo visual de servidores RP modernos.
- **Colores vibrantes**: Morado y fucsia como acento de interacción.
- **Distribución modular**: Interfaz por secciones, intuitiva para usuarios nuevos y experimentados.
