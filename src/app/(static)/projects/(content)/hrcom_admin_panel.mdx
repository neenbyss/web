## Acerca del Proyecto

Este panel administrativo fue diseñado para gestionar herramientas de ciberseguridad dentro de una infraestructura corporativa. Su objetivo es brindar visibilidad inmediata sobre el estado de reglas, filtros activos y ataques recientes. La interfaz centraliza la gestión de firewalls, ataques DDoS y otras actividades críticas del sistema.

## Características Destacadas

- Vista general de reglas activas, filtros y abusos.
- Notificaciones en tiempo real de ataques recientes, categorizadas por nivel de riesgo.
- Sistema de alertas visuales (colores e íconos) para facilitar la toma de decisiones.
- Módulos independientes para reglas, descubrimiento automático y filtrado de abuso.

## Estilo Visual

- **Diseño Oscuro**: Interfaz con fondo dark, ideal para uso prolongado.
- **Código de Colores**: Verde para eventos resueltos, amarillo para advertencias y rojo para amenazas destructivas.
- **Tipografía Clara**: Facilita la lectura rápida de logs y notificaciones.
- **Layout Minimalista**: Navegación lateral, tarjetas informativas y panel centralizado.

## Tecnologías Utilizadas

- **Next.js**: Framework React para manejo dinámico de rutas y vistas.
- **TailwindCSS**: Utilizado para un diseño rápido y consistente.
- **Modular Design**: Cada sección del panel está diseñada como módulo independiente.

Este proyecto representa una solución robusta y adaptable para entornos que requieren vigilancia constante, priorizando la claridad visual y eficiencia operativa.
