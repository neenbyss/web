## Acerca del Proyecto

Este proyecto consistió en la creación de un diseño completo de interfaz para **Hennus**, una plataforma de hosting especializada en servidores de videojuegos como FiveM, Minecraft y otros. Se desarrolló completamente en Figma, con enfoque visual moderno, intuitivo y adaptable para implementación posterior en frontend.

## Características del Diseño

- Dashboard para clientes con acceso a tickets, servicios y facturación.
- Página de producto para contratación de servicios con CTA claros.
- Secciones informativas con enfoque comercial (seguridad, rendimiento, beneficios).
- Menú lateral para gestión de cuentas, servidores y soporte.
- Versión oscura, pensada para usuarios del entorno gamer.

## Estilo Visual

- **Diseño Dark Mode**: Estética moderna enfocada en la audiencia gamer.
- **Paleta Azul/Violeta**: Refuerza sensaciones de seguridad y tecnología.
- **Componentes Reutilizables**: Estructura lista para maquetación con frameworks modernos.
- **Tipografía Negrita**: Lectura clara de secciones clave y llamados a la acción.

## Herramientas Utilizadas

- **Figma**: Creación del diseño completo en alta fidelidad.
- **Prototipado**: Navegación interactiva para validación antes del desarrollo.

Este diseño sirve como base sólida para el desarrollo de una plataforma profesional de hosting con enfoque en videojuegos y servicios digitales.
